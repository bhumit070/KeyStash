# KeyStash store assets

Marketing/store images for the Chrome Web Store listing. All sample data shown in
these images is **non-sensitive** (public profile links, email, phone, address) to
stay consistent with the project's guidance to never store secrets in KeyStash.

## Ready to upload (`store-ready/`)

These are sized to the exact dimensions the Chrome Web Store expects:

| File | Size | Store slot |
| --- | --- | --- |
| `store-ready/icon-128x128.png` | 128x128 | Store icon (required) |
| `store-ready/screenshot-1-popup-1280x800.png` | 1280x800 | Screenshot (at least 1 required) |
| `store-ready/screenshot-2-spotlight-1280x800.png` | 1280x800 | Screenshot |
| `store-ready/small-promo-440x280.png` | 440x280 | Small promo tile (optional) |
| `store-ready/marquee-1400x560.png` | 1400x560 | Marquee promo tile (optional) |

## Source images (high-res originals)

Full-resolution versions you can re-crop or restyle if needed:

- `keystash-icon.png` (1024x1024) — app logo

## Notes

- These are AI-generated **mockups** that closely match the real UI. For the best
  listing, consider replacing the two screenshots with real captures of the running
  extension at 1280x800.
- The `store-ready` copies were scaled/cropped from the 3:2 source art, so minor
  cropping or slight scaling may be visible. Regenerate or re-crop if you want a
  pixel-perfect fit.
